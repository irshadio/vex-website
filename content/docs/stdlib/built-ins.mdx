description: Every built-in function, type and constraint, and every member of strings, lists, maps and channels, with signatures, edge cases and the runtime errors they can raise.

Built-ins are the functions, types and members that every Vex file can use without an import. This page lists all of them. The signatures use `T` for a list's element type, `K` and `V` for a map's key and value types, and `?` for an optional result.

Built-in names are reserved. You can't name a variable, function, parameter or type `print`, `println`, `input`, `panic`, `assert`, `str`, `int`, `float`, `bool`, `string`, `void` or `Error`:

```text
error: 'str' is a built-in function and can't be used as a variable name
 --> reserved.vx:2:9
  |
2 |     let str = "x"
  |         ^^^ choose another name
```

The async helpers `run`, `all` and `any` are the exception: a function of your program with the same name replaces them.

## Functions

| Function | Result | Description |
|---|---|---|
| `print(values...)` | `void` | Writes the values separated by spaces, with no line ending |
| `println(values...)` | `void` | Writes the values separated by spaces, then a line ending |
| `input(prompt: string = "")` | `string` | Writes the prompt and reads one line from standard input |
| `str(value)` | `string` | Converts any value to text, the way `println` shows it |
| `int(value)` | `int` | Converts an `int`, `float` or `string` to `int` |
| `float(value)` | `float` | Converts an `int`, `float` or `string` to `float` |
| `panic(message: string)` | never returns | Stops the program with the message |
| `assert(condition: bool, message: string = "")` | `void` | Stops the program when the condition is false |
| `run(future)` | the future's value | Waits for a future from code that isn't async |
| `all(futures)` | a future | Waits for every future in a list |
| `any(futures)` | a future | Waits for the first future in a list to finish |

### print and println

`print` and `println` take any number of values of any type that has a value, and write them to standard output separated by single spaces. `println` adds a line ending; `println()` with no arguments writes only the line ending.

```vex title="printing.vx"
struct Point {
    x: int
    y: int
}

enum Shape {
    circle(radius: float)
    dot
}

fn main() {
    print("a", 1, 2.5, true)
    print("b")
    println()
    println("x", 3, [1, 2], ["k": 1])
    println(Point(x: 1, y: 2), Shape.circle(radius: 1.5), Shape.dot)
    let maybe: int? = nil
    println(maybe, (1, "a"), (x: 1, y: 2.5))
    println(["x", "y\n"], "y\n".len)
}
```

```text title="Output"
a 1 2.5 trueb
x 3 [1, 2] ["k": 1]
Point(x: 1, y: 2) Shape.circle(radius: 1.5) Shape.dot
nil (1, "a") (x: 1, y: 2.5)
["x", "y\n"] 2
```

How values print:

- Strings print as they are at the top level, and quoted with escapes inside lists, maps, structs, enums and records.
- Floats always show a decimal point or an exponent, so `3.0` prints as `3.0`, never `3`. They use the shortest text that reads back as the same number: `0.1 + 0.2` prints `0.30000000000000004`. Very large and very small values use an exponent (`1e+17`, `1e-06`); infinities and NaN print as `inf`, `-inf` and `nan`.
- Structs print as `Name(field: value, ...)` and enum cases as `Enum.case` or `Enum.case(field: value)`. A struct that refers back to itself prints the repeat as `Name(...)` instead of looping forever.
- Optionals print their value, or `nil`.
- Functions print their type, such as `<fn() -> int>`.

Passing something with no value, such as the result of a `void` function, is a compile error: `this expression has no value to print`.

Output to standard output is buffered. The runtime flushes it before it writes an error, before `os.run` and `os.output` start a command, and when the program ends, so output and error messages appear in order.

### input

`input` writes its optional prompt without a line ending, then reads one line from standard input and returns it without the trailing `\n` or `\r\n`. At the end of input it returns an empty string, so a program reading in a loop should stop on `""` if the input may end.

```vex title="ask.vx"
fn main() {
    let name = input("Name: ")
    let age = int(input("Age: "))
    println("Hi {name}, next year you turn {age + 1}")
}
```

```sh
printf 'Ann\n 41 \n' | vex run ask.vx
```

```text title="Output"
Name: Age: Hi Ann, next year you turn 42
```

The prompts and the answer appear on one line here because the input came from a pipe, not a keyboard.

### str

`str(value)` accepts a value of any type and returns the text `println` would print for it. Inside string interpolation you rarely need it: `"{n} items"` converts `n` the same way.

```vex title="str.vx"
fn main() {
    println(str(42) + str(1.5) + str(true))
    println(str([1, 2]), str(Error("boom")))
    let missing: string? = nil
    println(str(missing), "{missing}")
}
```

```text title="Output"
421.5true
[1, 2] Error(message: "boom")
nil nil
```

### int and float

`int(x)` and `float(x)` take exactly one `int`, `float` or `string`. Converting a `bool` or any other type is a compile error: `can't convert bool to int`.

| Call | Behavior |
|---|---|
| `int(3.9)`, `int(-3.9)` | Drops the fraction, rounding toward zero: `3`, `-3` |
| `int(1e30)`, `int(nan)` | Runtime error: the value doesn't fit in an `int` |
| `int("  42 ")` | Parses a decimal integer, ignoring spaces, tabs and line endings around it: `42` |
| `int("+7")`, `int("-17")` | A leading sign is allowed |
| `int("12abc")`, `int("0x1F")`, `int("")` | Runtime error: not a decimal integer |
| `int("99999999999999999999")` | Runtime error: the number is too big |
| `float(7)` | `7.0` |
| `float(" 1e3 ")` | Parses a decimal number with an optional fraction and exponent: `1000.0` |
| `float("abc")`, `float("inf")`, `float("nan")`, `float("0x10")` | Runtime error: only decimal numbers are accepted |

```vex title="convert.vx"
fn main() {
    println(int("  42 "), int(3.9), int(-3.9), int("-17"))
    println(float("2.5"), float(7), float(" 1e3 "), int(2.5e3))
}
```

```text title="Output"
42 3 -3 -17
2.5 7.0 1000.0 2500
```

`int` and `float` never convert silently in arithmetic, so these functions are how you mix the two: `float(count) * price`. Whole-number literals are the one exception: `let price: float = 10` is allowed.

The runtime errors look like this:

```text
error: can't convert "12abc" to int
 --> toint.vx:2
```

See [Runtime errors](/docs/tools/runtime-errors) for every message.

### panic and assert

`panic(message)` stops the program at once with `error: <message>`, the source line and exit status 1. Use it for states that mean the program itself is wrong, not for failures a caller could handle; those are [errors](/docs/language/errors) thrown with `throw`.

`assert(condition, message)` does nothing when the condition is true. When it is false, it stops the program like `panic`, printing `assertion failed` and the message if you gave one. Assertions always run; there is no release mode that removes them.

```vex title="checks.vx"
fn average(xs: [int]) -> int {
    assert(xs.len > 0, "average needs at least one number")
    var total = 0
    for x in xs {
        total += x
    }
    return total / xs.len
}

fn main() {
    println(average([2, 4, 9]))
    println(average([]))
}
```

```text title="Output"
5
error: assertion failed: average needs at least one number
 --> checks.vx:2
```

The error goes to standard error and the program exits with status 1. Because `panic` never returns, it can end a function that must return a value, or a `catch` block that must give one.

### run, all and any

These three work with futures, which async functions return when you call them without `await`. They are covered in depth in [Async and await](/docs/concurrency/async).

| Call | Result | Behavior |
|---|---|---|
| `run(f: Future<T>)` | `T` | Runs the event loop until `f` is done and returns its value. Only for code that isn't async; inside an async function it is a compile error. Needs `try` when the future can fail. |
| `all(fs: [Future<T>])` | `Future<[T]>` | Completes with every value, in the order of the list. With `Future<void>` items it gives `Future<void>`. It waits for the futures in list order and fails with the error of the first one in the list that fails. |
| `any(fs: [Future<T>])` | `Future<T>` | Completes with the value, or the error, of the first future to finish. An empty list is a runtime error: `any() needs at least one future`. |

```vex title="futures.vx"
import "vex:time"

async fn fetch(name: string, ms: int) -> string {
    await time.sleep(ms)
    return name
}

async fn main() {
    let both = await all([fetch("a", 30), fetch("b", 10)])
    println(both)
    let first = await any([fetch("slow", 50), fetch("quick", 5)])
    println(first)
    await all([time.sleep(5), time.sleep(10)])
    println("slept")
}
```

```text title="Output"
["a", "b"]
quick
slept
```

## Types

| Type | Description |
|---|---|
| `int` | 64-bit signed integer. Overflow stops the program; `&+`, `&-` and `&*` wrap around |
| `float` | 64-bit IEEE 754 floating-point number |
| `bool` | `true` or `false` |
| `string` | Immutable UTF-8 text |
| `[T]` | List of `T` |
| `[K: V]` | Map from `K` to `V` |
| `T?` | Optional `T`: a value or `nil` |
| `Error` | The built-in error struct, with one field, `message: string` |
| `Future<T>`, `Future<T, E>` | A value that will be ready later, which can fail with `E` |
| `Channel<T>` | A queue of `T` values shared between isolates |

The [Built-in types](/docs/language/types) page covers the language rules for each one.

### Error

`Error` is a struct with a single field, `message`. Create one with `Error("text")` or `Error(message: "text")`, throw it from a function marked `throws`, and read `e.message` in a `catch` block.

```vex title="error.vx"
fn parsePort(text: string) throws -> int {
    if text == "" {
        throw Error("empty port")
    }
    return int(text)
}

fn main() {
    let port = try parsePort("") catch e {
        println("bad port: {e.message}")
        8080
    }
    println(port)
    println(Error(message: "named"))
}
```

```text title="Output"
bad port: empty port
8080
Error(message: "named")
```

### Channel

`Channel<T>()` creates a channel. It needs no import, though channels are almost always used with `vex:isolate`. Its four members are documented on the [isolate](/docs/stdlib/isolate#channels) page:

| Member | Result | Description |
|---|---|---|
| `send(value: T)` | `void` | Copies the value into the channel; never waits |
| `receive()` | `Future<T?>` | Waits for the next value without blocking the isolate; `nil` once the channel is closed and empty |
| `receiveSync()` | `T?` | Waits for the next value, blocking the whole isolate |
| `close()` | `void` | Lets receivers finish once the values already sent are delivered |

## Constraints

Three built-in constraints can bound a [generic](/docs/language/generics) type parameter, as in `fn largest<T: Comparable>(items: [T]) -> T`:

| Constraint | Types that meet it |
|---|---|
| `Equatable` | `int`, `float`, `bool`, `string`, enums whose cases carry no values, and structs that define `operator ==` |
| `Comparable` | `int`, `float`, `string`, enums whose cases carry no values, and structs that define `operator <` and `operator ==` |
| `Hashable` | `int`, `string`, `bool`, and enums whose cases carry no values |

`Equatable` is what `==` and list `contains` need, `Comparable` is what `<` needs, and `Hashable` is what a map key needs.

## String members

Strings are immutable: every member that changes text returns a new string. Indexes and lengths count Unicode code points (characters), not bytes.

| Member | Result | Description |
|---|---|---|
| `len` | `int` | The number of code points. A property, written without `()` |
| `upper()` | `string` | The text with `a` to `z` changed to `A` to `Z` |
| `lower()` | `string` | The text with `A` to `Z` changed to `a` to `z` |
| `contains(text: string)` | `bool` | Whether `text` appears anywhere; always true for `""` |
| `startsWith(text: string)` | `bool` | Whether the string begins with `text` |
| `endsWith(text: string)` | `bool` | Whether the string ends with `text` |
| `indexOf(text: string)` | `int?` | The code-point index of the first match, or `nil` |
| `substring(from: int, to: int)` | `string` | The code points from `from` up to, not including, `to` |
| `split(separator: string)` | `[string]` | The pieces between each separator, keeping empty pieces |
| `replace(old: string, with: string)` | `string` | The text with every `old` replaced by `with` |
| `trim()` | `string` | The text without spaces, tabs and line endings at both ends |
| `trimStart()` | `string` | The same, at the start only |
| `trimEnd()` | `string` | The same, at the end only |
| `chars()` | `[string]` | Each code point as its own string |
| `lines()` | `[string]` | Each line, without its `\n` or `\r\n` |

Strings can't be indexed with `[]`. Use `substring(i, i + 1)` for one character, or `chars()` to walk them all.

### Length, case and searching

```vex title="search.vx"
fn main() {
    let t = "Hello, World"
    println(t.len, t.upper(), t.lower())
    println(t.contains("World"), t.contains(""), t.startsWith("Hell"), t.endsWith("d"))
    println(t.indexOf("o"), t.indexOf("xyz"), "héllo".indexOf("l"))
    println("é".len, "👍🏽".len, "👍🏽".chars())
    println("Ärger".upper(), "ÉCOLE".lower())
}
```

```text title="Output"
12 HELLO, WORLD hello, world
true true true true
4 nil 2
1 2 ["👍", "🏽"]
ÄRGER École
```

- `len` counts code points, so an emoji with a skin-tone modifier counts as 2, and `chars()` splits it in two.
- `upper()` and `lower()` change only the ASCII letters for now. `Ä` and `É` stay as they are.
- `indexOf` returns an optional; unwrap it with `if let` or give a default with `??`.

### Slicing and splitting

```vex title="slices.vx"
fn main() {
    let t = "Hello, World"
    println(t.substring(0, 5), t.substring(7, 12), "héllo".substring(1, 3))
    println("a,b,,c".split(","), "abc".split("abc"), "".split(","))
    println("héy".chars())
    println("line1\nline2\r\nline3\n".lines(), "a\n\nb".lines(), "".lines())
}
```

```text title="Output"
Hello World él
["a", "b", "", "c"] ["", ""] [""]
["h", "é", "y"]
["line1", "line2", "line3"] ["a", "", "b"] []
```

- `substring(from, to)` needs `0 <= from <= to <= len`. Anything else stops the program: `substring(2, 10) is out of range for a string of length 5`.
- `split` keeps empty pieces, so a separator at either end gives an empty string there, and splitting `""` gives `[""]`. An empty separator stops the program: `split separator can't be empty`.
- `lines()` drops one final line ending, so `"a\n"` gives `["a"]`, and `""` gives `[]`.

### Replacing and trimming

```vex title="tidy.vx"
fn main() {
    let s = "  Hello, World  "
    println("[{s.trim()}]", "[{s.trimStart()}]", "[{s.trimEnd()}]")
    println("Hello".replace("l", "L"), "aaa".replace("a", "bb"))
}
```

```text title="Output"
[Hello, World] [Hello, World  ] [  Hello, World]
HeLLo bbbbbb
```

- `trim`, `trimStart` and `trimEnd` remove spaces, tabs, `\n` and `\r`.
- `replace` replaces every match, scanning left to right. An empty `old` stops the program: `replace needs text to look for, not an empty string`.

For repeating, joining and padding, see [vex:strings](/docs/stdlib/strings).

## List members

Lists are shared references: `let b = a` makes `b` another name for the same list. `let` stops the name from being reassigned, not the list from being changed.

| Member | Result | Description |
|---|---|---|
| `len` | `int` | The number of items. A property, written without `()` |
| `push(item: T)` | `void` | Adds the item at the end |
| `pop()` | `T` | Removes and returns the last item; stops the program if the list is empty |
| `contains(item: T)` | `bool` | Whether an item is `==` to `item`; needs an `Equatable` element type |
| `filter(keep: fn(T) -> bool)` | `[T]` | A new list of the items `keep` returns true for |
| `map(f: fn(T) -> R)` | `[R]` | A new list of what `f` returns for each item |
| `copy()` | `[T]` | A new list with the same items |

Indexing with `xs[i]` reads and `xs[i] = v` writes. An index below 0 or at or past `len` stops the program.

```vex title="lists.vx"
fn main() {
    var nums = [3, 1, 4]
    nums.push(1)
    println(nums, nums.len)
    let last = nums.pop()
    println(last, nums)
    println(nums.contains(4), nums.contains(9))
    println([1, 2, 3, 4, 5, 6].filter(fn(n) => n % 2 == 0))
    println(nums.map(fn(n) => "#{n}"))

    let copy = nums.copy()
    copy.push(99)
    let alias = nums
    alias.push(7)
    println(nums, copy)
}
```

```text title="Output"
[3, 1, 4, 1] 4
1 [3, 1, 4]
true false
[2, 4, 6]
["#3", "#1", "#4"]
[3, 1, 4, 7] [3, 1, 4, 99]
```

- `copy()` is shallow: a list of structs copies the references, not the structs.
- `map` needs a function that returns a value. It can't be torn off as a function value yet (`'map' can't be used as a value`); the other members can, as in `let add = nums.push`.
- A list from a `const` can't be changed. Changing it through another name stops the program: `can't change a constant list; change a copy made with .copy()`.

More on lists, including collection `if`, `for` and spread, is on [Lists](/docs/language/lists).

## Map members

Maps are shared references too. They keep their keys in the order they were first added.

| Member | Result | Description |
|---|---|---|
| `len` | `int` | The number of entries. A property |
| `keys` | `[K]` | The keys, in insertion order. A property |
| `values` | `[V]` | The values, in insertion order. A property |
| `contains(key: K)` | `bool` | Whether the key is present |
| `remove(key: K)` | `V?` | Removes the key and returns its value, or `nil` if it was missing |
| `copy()` | `[K: V]` | A new map with the same entries |

Reading `m[key]` gives a `V?`, which is `nil` when the key is missing, and `m[key] = value` adds or replaces an entry.

```vex title="maps.vx"
fn main() {
    var ages = ["ann": 31, "bob": 25]
    ages["cat"] = 40
    println(ages.len, ages.keys, ages.values)
    println(ages.contains("ann"), ages.contains("zoe"))
    println(ages.remove("bob"), ages.remove("bob"), ages)
    println(ages["ann"], ages["zoe"], ages["zoe"] ?? 0)
    let backup = ages.copy()
    backup["dan"] = 1
    println(ages.len, backup.len)
}
```

```text title="Output"
3 ["ann", "bob", "cat"] [31, 25, 40]
true false
25 nil ["ann": 31, "cat": 40]
31 nil 0
2 3
```

Maps have no `get`, `has`, `set` or `delete`. Using one of those names gives a hint toward the Vex way, such as `use .contains(key)` or `read a key with m[key], which gives nil when it is missing`. See [Maps](/docs/language/maps) for keys, iteration and the rules for optional values.

## int and float

`int` and `float` have no built-in members. Math functions live in [vex:math](/docs/stdlib/math), conversion is `int(...)`, `float(...)` and `str(...)`, and you can add members yourself:

```vex title="extend.vx"
extension int {
    fn isEven() -> bool => self % 2 == 0
    get squared -> int => self * self
}

fn main() {
    println(4.isEven(), 7.isEven(), 9.squared)
}
```

```text title="Output"
true false 81
```
